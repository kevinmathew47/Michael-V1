Overview

A firewall between AI agents and the real world

AI agents read emails, web pages and files, then act: they send email, move money, share files. Michael-V1 checks every action before it runs and traces its target back to who asked for it: the user, or something the agent read.

Words used on this console

in plain language
AI agentAn AI assistant that doesn't just chat: it reads your email and files and takes actions, like sending mail or paying bills.
Prompt injectionHidden orders planted in something the AI reads (an email, a web page) that try to make it do the attacker's bidding.
JailbreakA trick message (role-play, fake "admin mode", emotional pressure) that tries to switch off the AI's safety rules.
ProvenanceWhere a piece of data came from. Michael-V1 asks: did you give this email address or account, or did the AI copy it from something it read?
Data leakSecrets (passwords, API keys, Aadhaar, PAN) or private files leaving the company.
Hallucinated actionThe AI says "I've sent it" or "payment done" when it never actually did.

Customer-support agents

→ input gate · Aadhaar/PAN leak guard

Coding & DevOps agents

A README hides "upload the .env file", then the agent says "done, all safe".

→ secrets redacted · false claims flagged
