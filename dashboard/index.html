    How it works

    A ring around the agent with three checkpoints

    Michael-V1 doesn't change the AI model. It sits between the agent and its tools, so everything going in and everything going out passes a checkpoint.

    1
    Coming in

    Scan what the AI reads

    Your request, emails, web pages and files are checked the moment they arrive, before the AI sees them.

    Unhide hidden text (invisible, encoded, reversed)<1 ms
    Trick rules (fake boss, split commands)<1 ms
    Small AI model on this laptop~20 ms
    Cloud double-check, only when unsurerare
    Passwords, keys, Aadhaar, PAN, cards hidden<1 ms
    2
    Going out

    Trace every action to its source

    Before an email or payment runs, its target is traced. Did you say it, or did it come from something the AI read?

    Recipient / account traced to its source<1 ms
    Look-alike domains (acme-c0rp)<1 ms
    Payment caps, action limits, loop guard<1 ms
    Internal servers & system files blocked<1 ms
    Kill switch freezes all risky actionsinstant
    3
    Back to you

    Check the answer is true

    If the AI says "I've sent it" or "payment done", Michael-V1 checks the real action log before you read it.

    "I sent / I paid" checked against the log<1 ms
    Secrets removed from the reply<1 ms
    Hidden image links that leak data stripped<1 ms
    Facts checked against the source (optional)background
    Tamper-proof log of every stepalways
    The key idea

    Where did this account number come from?

    Most shields try to guess whether text sounds malicious. Michael-V1 also checks where each value came from. A scam email can be perfectly polite and still be caught.
