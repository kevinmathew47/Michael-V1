    01 · Trust flow, not text filters

    Asks "who chose this target?"

    Every email address, account and file the agent acts on is traced back to its source. If an email or web page picked it, a risky action is stopped, even when the text looks harmless and every AI detector scores it safe.

    02 · Catches lies about actions

    "I sent it" is checked against reality

    Claims like "I've replied to the vendor" are matched against the actual action log by code. An AI never grades itself.

    03 · Drop-in, no rewrite

    Four hooks around any tool-calling agent

    No custom interpreter, no second agent, no proxy. Normal tasks keep working: 6/6 in our suite with zero false alarms.

    04 · Latency budget by risk

    Pay only before risky actions

    Read-only steps are near-free, AI checks run in parallel while the agent thinks, risky actions fail closed. Every check is timed on screen.

    05 · Judged by damage

    Money moved, files leaked, secrets exposed

    The attack suite scores real side effects, not model output, and every recorded run can be replayed in the Flow Lab.

    06 · India-ready DLP

    Aadhaar with Verhoeff checksum, PAN

    Aadhaar numbers are validated with UIDAI's checksum, so random 12-digit numbers aren't flagged as personal data.
