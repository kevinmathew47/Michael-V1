Inside the shield

Five checkpoints between the AI and the real world

Michael-V1 doesn't change the AI model. It wraps the agent's tools, so everything coming in and going out passes these checkpoints, in this order.

01

Check the request

Hidden text is decoded, trick rules run, then a small AI model on this machine decides. Only unsure cases go to the cloud.

~20 ms
02

Scan what the AI reads

Emails, web pages and files are scanned on arrival. Hidden orders are quarantined; passwords, keys, Aadhaar, PAN and cards are hidden.

<1 ms
03

Trace every action

The recipient or account of each email and payment is traced. If it came from something the AI read, not from you, it's blocked.

<1 ms
04

Enforce the limits

Look-alike domains, payment caps, action limits, loop guard, internal servers, system files and a kill switch.

<1 ms
05

Check the answer

"I sent it" or "payment done" is checked against the real action log; secrets and data-leaking links are removed.

<1 ms
The key idea

Where did this account number come from?

Other shields guess if text sounds malicious. Michael-V1 also checks where each value came from, so even a polite scam email is caught.

1 · Attack the shield itself

When the shield is attacked, everything freezes

If someone edits the shield's policy, swaps a tool or forges an approval, Michael-V1 doesn't just block one action: it freezes every action of every task, reads included, until the owner unlocks it in the private Approver. Text that pretends to be the shield freezes its own task. Pick an attack:

2 · Asking the owner, privately

The approval never happens on this page

When a target is not proven bad but not proven safe (nobody named it), the shield asks the owner. A web page can be injected or clicked by a script, so the question goes to a separate, private app. This dashboard can only show that it is waiting.

If something goes wrong

            
"python" is not recognized
Install Python from python.org and tick Add Python to PATH, then open a new terminal. On Mac/Linux use python3.

            
The shield says SYSTEM FROZEN
It saw an attack on itself (or its policy file changed). Open the Owner Vault at http://127.0.0.1:8765, sign in, and press Unlock the shield.

            
I edited policy.yaml and now everything is frozen
That is the tamper protection. Pin your edit on purpose: python -m michael.shield.integrity --pin, then unlock in the Owner Vault.

            
I forgot the owner password
Delete the file ~/.michael/owner_pin (Windows: C:\Users\<you>\.michael\owner_pin) and open the Owner Vault to create a new account.

            
Port 8000 is already in use
Close the other program, or stop an older Michael-V1 window. Then run michael-server again.

            
pip install is slow or very large
Install the smaller CPU build of PyTorch first: pip install torch==2.4.1 --index-url https://download.pytorch.org/whl/cpu.
